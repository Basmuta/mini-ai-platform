# صدى | Sada Reviews

**Arabic App Review Intelligence** — نموذج أولي لتحليل مراجعات التطبيقات العربية واللهجات والإنجليزية.

## المشكلة
تتوزع ملاحظات مستخدمي التطبيقات بين متاجر المراجعات، وقد يصعب على فريق منتج صغير معرفة أكثر المشكلات تكرارًا. صدى يصنف المراجعة حسب الموضوع والمشاعر، ويعرض مؤشرات ورسومًا تساعد الفريق على بدء تحليل منظم.

## ما يقدمه النموذج الأولي
- تصنيف 7 موضوعات: تسجيل الدخول، الأعطال، الأداء، الدفع، سهولة الاستخدام، اقتراحات الميزات، والتجارب الإيجابية.
- تجربة جملة مباشرة أو تحميل CSV يحتوي عمودًا باسم review.
- لوحة تفاعلية لتوزيع الموضوعات والمشاعر، ومقاييس تجريبية.
- تقرير تجارب ثابت ورسوم SVG داخل reports.
- بيانات تشمل السعودي والمصري والمغربي/الدارجة والخليجي والعراقي والإنجليزية وArabizi.

## التشغيل
يتطلب Python 3.10 أو أحدث. من مجلد المشروع:

    pip install -r requirements.txt
    streamlit run app.py

## التجربة القابلة لإعادة التشغيل
ملف experiment.py يولد 1,960 مثالًا اصطناعيًا متوازنًا، ويقارن Word n-gram NB مع Character n-gram NB. ويختبر صيغًا بديلة محجوزة، ثم يجري stress test باستبعاد لهجة كاملة كل مرة. لتجديد النتائج والرسوم:

    python experiment.py
    python build_report.py

النتائج التفصيلية في reports/experiment_report.md وملفات JSON وSVG. أرقام التقرير محسوبة من تشغيل التجربة على البيانات المولدة، وليست أرقام أداء على مراجعات حقيقية.

## مفاهيم اللابات
- Lab 1 و4: تطبيع النص العربي ومراعاة اللغة واللهجة.
- Lab 3A: تصنيف موضوع المراجعة.
- Lab 6: Macro-F1 وAccuracy وتحليل الأداء حسب اللهجة ورسوم التقارير.
- Lab 2 و3B و5: يمكن توسيع المشروع لاحقًا بخريطة Attention، محاذاة subwords، وبحث دلالي عن مراجعات مشابهة.

## حدود مهمة
البيانات مصطنعة ومولدة من بذور لغوية محدودة لأغراض التعليم، وقد تظهر فيها أنماط أسهل من مراجعات المتاجر الحقيقية. النتائج لا تثبت الجاهزية للإنتاج ولا ينبغي عرضها كأداء على مستخدمين حقيقيين. الخطوة التالية هي جمع عينة عامة مسموح باستخدامها، إزالة المعرفات الشخصية، إعداد دليل تصنيف، ومراجعة الملصقات يدويًا.

لا ترفع مراجعات تحتوي أسماء أو أرقامًا أو معلومات حسابات شخصية. راجع شروط استخدام مصدر البيانات قبل إعادة توزيع أي مراجعات حقيقية.
